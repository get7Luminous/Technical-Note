01 · Technical guide

Overview

카메라와 ToF 센서의 정보를 한 개의 MCU에서 처리해, 얼굴 검출·생체성 확인·특징 추출·1:N 식별까지 수행하는 엣지 AI 데모입니다.

온디바이스RGB + ToF1:N Identification

One sentence

무엇을 보여주는 데모인가?

id3 MicroFace SDK를 STM32N6의 Neural-ART NPU에 최적화하여, 서버나 외부 가속기 없이 로컬에서 얼굴 식별 흐름을 완성합니다.

Why it matters

이 데모의 핵심 가치 4가지

01

로컬 처리

얼굴 특징과 판정을 장치 내부에서 다뤄 네트워크 의존성과 응답 변동을 줄입니다.

02

센서 결합

RGB 외형 정보에 8×8 ToF 깊이 단서를 더해 PAD 판단을 보강합니다.

03

MCU급 통합

Cortex-M55와 Neural-ART를 한 칩 안에서 조합해 제어와 AI 추론을 수행합니다.

04

작은 템플릿

한 얼굴의 등록 템플릿은 148 bytes 미만으로 제시되어 로컬 DB 구성에 유리합니다.

Glossary

핵심 용어

발표 중 자주 등장하는 표현을 짧게 정리했습니다.

Identification (1:N)
입력 얼굴을 등록된 여러 사람과 비교해 “누구인지” 찾는 과정.
Verification (1:1)
입력 얼굴이 주장한 한 사람과 같은지 확인하는 과정.
PAD / Liveness
사진·영상·마스크 같은 위변조 공격이 아니라 실제 사람인지 판단하는 절차.
Embedding / Template
얼굴을 비교 가능한 수치 특징으로 표현한 결과. 이 데모의 등록 템플릿은 148 bytes 미만으로 제시됨.
Quantization
신경망의 숫자 표현 정밀도를 줄여 연산량과 메모리 사용을 낮추는 배포 기법.
MACC
곱셈-누산 연산 수. 모델의 계산 복잡도를 나타내는 한 지표.
NPU
신경망의 행렬·합성곱 연산을 효율적으로 처리하도록 설계된 가속기.
ToF
빛이 돌아오는 시간을 이용해 거리를 측정하는 센서 방식.
✓

공식 확인 범위

세 모델명, 센서 구성, 성능·메모리 수치, Neural-ART 가속은 ST 공식 case study에 공개되어 있습니다.
