39Normalization

Float model에서는 예를 들어 pixel 0~255를

-1 ~ +1

범위로 변환할 수 있다.

수식은

x′ = x / 127.5 − 1

이다.

예를 들어

Pixel 0
→ -1

Pixel 127.5
→ 0

Pixel 255
→ +1

이다.

42Quantization의 기본 원리

Float 값을 integer로 표현한다.

대략

q = round(x / scale) + zeroPoint

와 같은 관계를 사용한다.

반대로

x ≈ scale × (q − zeroPoint)

이다.

따라서 INT8 값만 저장하고 계산하면서도 원래 float 값과 비슷한 의미를 표현할 수 있다.

43Calibration Dataset

Quantization을 제대로 하기 위해서는 실제 입력 데이터 범위를 알아야 한다.

따라서 Training dataset 중 일부를 사용하여

Layer activation range

를 측정한다.

이를 Calibration 또는 Representative Dataset이라고 한다.
