시스템과 카메라

카메라 입력과 보드의 하드웨어 경로

1. 목표2. 전체 Edge AI 시스템 구조3. STM32N6570-DK의 Hardware Pipeline4. External Component Driver와 Peripheral 설정5. DCMIPP의 역할

01목표

STM32N6570-DK의 카메라로 입력되는 영상을 분석하여 다음과 같은 동물을 실시간으로 분류하는 Edge AI 애플리케이션을 구현한다고 가정한다.

Dog
Cat
Lion
Tiger
Elephant
Other

이 애플리케이션은 Image Classification 문제이다.

즉,

Camera Image
→
"What animal is this?"
→
Lion : 93.2 %

처럼 한 영상 또는 한 ROI에서 가장 가능성이 높은 하나의 클래스를 선택한다.

사자와 개의 위치까지 각각 찾아 Bounding Box를 그리는 것이 목적이라면 Image Classification이 아니라 Object Detection을 사용해야 한다.

각 블록의 역할을 구분하는 것이 중요하다.

3.1 Camera Sensor

STM32N6570-DK에서 사용하는 카메라 모듈의 sensor는 IMX335 계열이다.

Camera sensor 내부에서는 다음과 같은 작업이 이루어진다.

빛
→
Pixel sensor
→
Analog signal
→
ADC
→
Digital pixel data

MCU가 카메라를 제어하기 위해서는 두 가지 경로가 필요하다.

원문 텍스트 도식 보기
I2C
 └─ Register configuration

MIPI CSI-2
 └─ Image pixel transfer

I2C를 통해서는 다음과 같은 값을 설정한다.

Resolution
Frame rate
Exposure
Gain
Pixel format
Streaming start / stop

실제 영상 데이터는 I2C가 아니라 MIPI CSI-2를 통해 전달된다.

05DCMIPP의 역할

DCMIPP는 단순히 Camera data를 memory로 옮기는 peripheral이라고만 보면 부족하다.

Vision application에서는 Image preprocessing hardware 역할까지 수행할 수 있다.

예를 들어 카메라 영상이

1920 × 1080

이고 DNN의 입력이

224 × 224

라면 전체 영상을 그대로 DNN에 넣을 수 없다.

따라서

1920×1080
→
Crop
→
Resize
→
Color conversion
→
224×224 RGB

과 같은 처리가 필요하다.

가능하다면 CPU에서 pixel을 하나씩 계산하기보다 DCMIPP와 같은 hardware block을 활용하는 것이 좋다.
