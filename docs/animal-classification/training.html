06Dataset 설계

이 AI의 성능을 결정하는 가장 중요한 요소 중 하나가 Dataset이다.

예를 들어 다음과 같이 클래스를 정의한다.

Class 0 : Dog
Class 1 : Cat
Class 2 : Lion
Class 3 : Tiger
Class 4 : Elephant
Class 5 : Other

Dataset은 다음처럼 구성할 수 있다.

dataset/
│
├── train/
│   ├── dog/
│   ├── cat/
│   ├── lion/
│   ├── tiger/
│   ├── elephant/
│   └── other/
│
├── validation/
│   └── ...
│
└── test/
    └── ...

07왜 Other Class가 필요한가?

Softmax 기반 classifier는 기본적으로 다음 질문에 답한다.

"이 이미지가 현재 등록된 클래스 중 무엇과 가장 가까운가?"

따라서 화면에 책상만 있어도 출력은 나올 수 있다.

예를 들어

Dog       28 %
Cat       19 %
Lion      24 %
Tiger     11 %
Elephant   8 %

처럼 의미 없는 결과가 나올 수 있다.

따라서 다음과 같은 데이터를 Other에 포함시키는 것이 좋다.

사람
자동차
책상
나무
빈 화면
실내
건물
등록되지 않은 동물

그러면 DNN이

Known animal
vs
Other

도 함께 학습할 수 있다.

08Dataset에서 중요한 것은 양보다 다양성

예를 들어 Lion dataset에 정면 사자 사진만 많다면 실제 환경에서는 성능이 낮아질 수 있다.

따라서 다음 조건들이 포함되어야 한다.

Front / Side view

Near / Far

Bright / Dark

Different backgrounds

Partial occlusion

Different sizes

Motion blur

Different camera angles

특히 최종 제품에서는 실제 STM32N6570-DK Camera로 촬영한 이미지도 dataset에 포함시키는 것이 좋다.

이것을 Domain Gap을 줄인다고 볼 수 있다.

09Model 선택

이 프로젝트에서는 MobileNetV2를 좋은 시작점으로 볼 수 있다.

이유는 다음과 같다.

상대적으로 작은 모델

연산량이 적음

Embedded AI에 적합

Quantization이 용이함

CNN의 핵심 구조를 공부하기 좋음

구성은 다음처럼 시작할 수 있다.

Model     : MobileNetV2

Input     : 224 × 224 × 3

Dataset   : Custom animal dataset

Pretrain  : ImageNet

Output    : 6 classes

Precision : INT8

10Pretrained Model은 무엇인가?

MobileNetV2 구조 자체와 학습된 weight는 구분해야 한다.

원문 텍스트 도식 보기
MobileNetV2
     │
     ├─ Network Architecture
     │
     └─ Weights

Architecture는

Conv
Depthwise Conv
BatchNorm
Activation
Residual block
...

같은 연결 구조를 의미한다.

Weight는 실제 학습을 통해 얻어진 숫자들이다.

예를 들어

w1 = 0.214
w2 = -0.532
w3 = 1.083
...

와 같은 값이 수백만 개 존재한다.

11ImageNet Pretraining

MobileNetV2를 처음부터 학습할 수도 있지만 일반적으로 ImageNet으로 이미 학습된 weight를 사용한다.

ImageNet Dataset
→
MobileNetV2 Training
→
Pretrained MobileNetV2

이미 학습된 network는 초반 layer에서 다음과 같은 feature를 검출하는 능력을 갖고 있다.

Edge

Corner

Texture

Color pattern

Shape

따라서 우리가 처음부터 모든 것을 다시 학습할 필요가 없다.

12Transfer Learning

우리가 원하는 것은 ImageNet의 1000개 클래스를 분류하는 것이 아니다.

따라서 기존 classifier를 제거한다.

원문 텍스트 도식 보기
Pretrained MobileNetV2
          │
          ↓
Feature Extractor
          │
          X
ImageNet 1000-class classifier 제거

대신 새로운 classifier를 연결한다.

Feature Extractor
→
Dense
→
6 Outputs

즉

Dog
Cat
Lion
Tiger
Elephant
Other

를 학습한다.

이것이 Transfer Learning이다.

13Fine-tuning

처음에는 MobileNetV2 backbone을 고정할 수 있다.

Backbone
Weight update X

Classifier
Weight update O

먼저 새로운 classifier를 학습시킨다.

그다음 필요하다면 일부 backbone layer도 다시 학습시킨다.

Pretrained weight
→
Slight modification
→
Better fit to animal dataset

이것을 Fine-tuning이라고 한다.
