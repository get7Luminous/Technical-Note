15Input Layer

DNN 입력은 다음 형태이다.

224 × 224 × 3

Tensor로 표현하면 일반적으로

[1, 224, 224, 3]

이다.

각 의미는

1   : Batch

224 : Height

224 : Width

3   : RGB Channels

이다.

즉 DNN은 카메라 이미지를 그대로 이해하는 것이 아니라 숫자로 구성된 Tensor를 입력으로 받는다.

16Convolution Layer

CNN의 핵심은 Convolution이다.

간단히 말하면 작은 Filter를 이미지 위에서 이동시키면서 특정 feature를 찾는다.

예를 들어 3×3 filter라면

Image

x x x
x x x
x x x

영역에 대해

Filter

w1 w2 w3
w4 w5 w6
w7 w8 w9

를 적용한다.

계산은 대략

y = w₁x₁ + w₂x₂ + … + w₉x₉ + b

이다.

여기서

x = Input data

w = Weight

b = Bias

y = Output feature

이다.

17Weight는 무엇인가?

Weight는 DNN이 "무엇을 중요하게 볼 것인가"를 결정하는 학습된 parameter이다.

예를 들어 특정 filter가 수직 edge를 검출하도록 학습되었다면

Dark | Bright

와 같은 패턴에 강하게 반응하는 weight를 가지게 된다.

중요한 점은

사람이 "이 weight는 귀를 찾고, 이 weight는 털을 찾는다"고 직접 지정하는 것이 아니다.

Training 과정에서 Loss를 줄이도록 weight가 자동으로 업데이트된다.

18Activation Function

Convolution만 계속 사용하면 전체 network가 본질적으로 Linear function의 조합이 된다.

복잡한 패턴을 학습하려면 Nonlinearity가 필요하다.

MobileNetV2에서는 대표적으로 ReLU6를 사용한다.

ReLU6(x) = min(max(0, x), 6)

즉

x < 0
→ 0

0 ≤ x ≤ 6
→ x

x > 6
→ 6

이다.

예를 들어

Input

-3
 2
10

이면

Output

0
2
6

이 된다.

19Batch Normalization

Conv 뒤에는 흔히 Batch Normalization이 사용된다.

개념적으로는 layer의 출력 분포를 적절한 범위로 조정한다.

Conv output
→
Normalization
→
Scale
→
Offset

Training을 안정화하고 빠르게 만드는 데 도움이 된다.

Inference에서는 Training 중 계산된 parameter가 사용된다.

20MobileNetV2의 핵심: Depthwise Separable Convolution

일반 convolution은 연산량이 상당히 크다.

MobileNet 계열은 이를 두 단계로 나눈다.

Standard Convolution

Spatial filtering
+
Channel mixing

을

Depthwise Convolution
        +
Pointwise Convolution

으로 분리한다.

21Depthwise Convolution

RGB 또는 여러 feature channel에 대해 각 channel마다 독립적인 spatial filter를 적용한다.

Channel 1 ─→ Filter 1

Channel 2 ─→ Filter 2

Channel 3 ─→ Filter 3

즉 spatial feature를 찾는 역할이 크다.

22Pointwise Convolution

Pointwise convolution은

1 × 1 convolution

이다.

공간적으로 주변 pixel을 보는 것이 아니라 channel들을 서로 조합한다.

Channel 1
Channel 2
Channel 3
→
1×1 Conv
→
New channel representation

Depthwise + Pointwise를 사용하면 standard convolution보다 계산량을 크게 줄일 수 있다.

24Expansion은 무엇인가?

입력 channel이 예를 들어 32라면 내부 계산에서는 channel 수를 늘릴 수 있다.

32 Channels
→
1×1 Expansion
→
192 Channels

이렇게 feature 표현 공간을 넓힌다.

25Projection

Depthwise convolution 후 다시 channel 수를 줄인다.

192
→
1×1 Conv
→
32

이것이 Projection이다.

26왜 마지막에는 ReLU가 없는가?

MobileNetV2에서는 Projection 뒤에 일반적으로 ReLU6를 사용하지 않는다.

Expansion
↓
ReLU6
→
Depthwise
↓
ReLU6
→
Projection
↓
Linear

좁은 bottleneck feature에 activation을 적용하면 중요한 정보가 손실될 가능성이 있기 때문이다.

이를 Linear Bottleneck이라고 부른다.

27Residual Connection

입력과 출력 shape이 같을 경우 다음과 같은 연결을 사용할 수 있다.

원문 텍스트 도식 보기
Input ─────────────┐
                   +
Conv Blocks ───────┘
                   ↓
                 Output

수식으로는

y = F(x) + x

이다.

Network가 매우 깊어졌을 때 학습을 안정적으로 만드는 데 도움이 된다.

28CNN이 깊어지면서 Feature가 어떻게 변하는가?

초기 layer는 비교적 단순한 feature를 본다.

Edge

Line

Corner

Color change

조금 깊어지면

Texture

Hair pattern

Eye

Nose

Ear

더 깊어지면

Animal face

Body shape

Mane

Stripe pattern

최종적으로는

Dog-like representation

Cat-like representation

Lion-like representation

같은 고수준 feature가 형성된다.

중요한 점은 이런 feature 역시 사람이 직접 프로그램한 것이 아니라 학습된 weight의 결과라는 것이다.
