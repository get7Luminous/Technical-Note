45ST Edge AI Toolchain의 역할

INT8 TFLite 또는 ONNX 모델이 만들어졌다고 STM32가 그대로 실행할 수 있는 것은 아니다.

ST의 AI toolchain이 모델을 분석한다.

TFLite / ONNX
→
ST Edge AI Core
→
Operator Analysis
→
Memory Planning
→
Neural-ART Mapping
→
Executable Network

46Neural-ART NPU의 역할

Neural-ART Accelerator는 DNN 내부의 대량 계산을 담당한다.

예를 들어

Convolution

Depthwise Convolution

Pointwise Convolution

Activation

Pooling

같은 연산을 CPU보다 훨씬 효율적으로 처리한다.

전체 시스템 역할을 나누면 다음과 같다.

Neural-ART NPU
   │
   └─ DNN numerical computation

47Weight는 어디서 사용되는가?

Training 후 학습된 weight가 최종 모델 안에 저장된다.

원문 텍스트 도식 보기
Model
 │
 ├─ Network structure
 │
 └─ Millions of learned weights

Inference 시 NPU는

Input Tensor

+

Model Weights

를 사용하여 layer 계산을 수행한다.

즉 Neural-ART가 임의로 판단하는 것이 아니다.

Training에서 만들어진 weight를 기반으로 연산한다.

49Confidence Threshold

예를 들어

Lion : 42 %

라면 확신이 낮다고 볼 수 있다.

따라서

if confidence > 70 %
    show class
else
    show Unknown

처럼 처리할 수 있다.

50Temporal Filtering

Video에서는 frame마다 결과가 조금씩 변할 수 있다.

Frame 1
Lion 82 %

Frame 2
Tiger 55 %

Frame 3
Lion 87 %

Frame 4
Lion 91 %

그대로 표시하면 화면이 흔들려 보인다.

따라서 최근 여러 frame의 probability를 평균낼 수 있다.

Pfiltered =
(P1 + P2 + P3 + P4) / 4

또는 같은 class가 연속으로 몇 번 검출된 경우에만 결과를 변경할 수도 있다.

52Cache가 중요한 이유

DCMIPP 또는 DMA가 memory에 새 영상을 썼더라도 CPU cache에 예전 image가 남아 있을 수 있다.

예를 들어

Memory
Frame 100

CPU Cache
Frame 99

상태라면 CPU 또는 AI subsystem이 잘못된 데이터를 볼 수 있다.

따라서 DMA/DCMIPP와 CPU/NPU가 공유하는 buffer에 대해서는

Cache Clean

Cache Invalidate

Memory attributes

를 정확하게 관리해야 한다.

이는 STM32N6 같은 고성능 MCU에서 상당히 중요한 부분이다.

53Frame Buffer 구조

성능을 높이기 위해 하나의 buffer만 사용하는 것보다 여러 buffer를 사용하는 것이 좋다.

예를 들어 Double Buffering:

Buffer A
Camera Capture

Buffer B
AI Inference

다음 frame에서는

Buffer A
AI Inference

Buffer B
Camera Capture

처럼 역할을 바꾼다.

그러면

Capture
+
Inference

를 어느 정도 동시에 수행할 수 있다.
