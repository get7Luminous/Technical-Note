29Feature Map

CNN layer의 출력은 보통 여러 장의 feature map으로 표현된다.

예를 들어

7 × 7 × 1280

이라면

7 × 7 spatial information

×

1280 different features

를 의미한다.

각 channel은 서로 다른 feature에 반응한다.

30Global Average Pooling

마지막 CNN feature가

7 × 7 × 1280

이라면 7×7 공간의 평균을 각 channel마다 계산한다.

결과는

1 × 1 × 1280

즉

1280-dimensional vector

가 된다.

예를 들어

[
0.13,
0.81,
0.02,
...
0.56
]

와 같은 형태이다.

이 벡터는 이미지에서 추출된 고수준 feature 표현이라고 볼 수 있다.

31Embedding과의 관계

이 1280-dimensional feature vector는 넓은 의미에서 Embedding이라고 볼 수 있다.

즉 원래 이미지는

224 × 224 × 3
≈ 150,000 values

였지만 DNN이 의미 있는 feature를 추출하여

1280-dimensional representation

으로 변환하였다.

즉

Image
→
DNN Feature Extractor
→
Embedding

이다.

Image Classification에서는 이 embedding을 곧바로 classifier에 넣는다.

32Dense Layer

이제 1280개의 feature로부터 6개의 class score를 계산한다.

1280 Features
→
Dense Layer
→
6 outputs

하나의 출력은 다음과 같이 계산된다.

zᵢ = ∑ⱼ wᵢⱼhⱼ + bᵢ

여기서

h = Feature / Embedding

w = Learned weight

b = Bias

z = Class score

이다.

33Logit

Dense layer 출력은 보통 probability가 아니다.

예를 들어

Dog        1.1
Cat        0.7
Lion       4.2
Tiger      2.1
Elephant  -0.4
Other      0.1

같은 값일 수 있다.

이러한 값을 Logit이라고 한다.

크기가 클수록 해당 class를 더 강하게 예측한다는 뜻이다.

34Softmax

Logit을 사람이 이해하기 쉬운 확률 형태로 바꾸는 것이 Softmax이다.

Pi = ezi / ∑j ezj

결과는 예를 들어

Dog        3.5 %

Cat        2.4 %

Lion      83.5 %

Tiger      9.3 %

Elephant   0.5 %

Other      0.8 %

이다.

모든 값을 더하면

100 %

가 된다.

35Argmax

가장 높은 probability를 선택한다.

Dog       0.035

Cat       0.024

Lion      0.835   ← MAX

Tiger     0.093

따라서

Argmax
→
Lion

이다.
