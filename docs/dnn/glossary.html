07 • GLOSSARY

핵심 용어를
짧고 정확하게

구조 설명을 다시 읽을 때 필요한 개념만 빠르게 찾아볼 수 있습니다.

Architecture · 구조
층과 연산을 어떤 방식으로 연결할지 정한 신경망의 설계 방식
Layer · 층
입력을 받아 변환하고 다음 단계로 넘기는 계산 단위
Weight · 가중치
학습을 통해 조정되는 연결의 중요도
Bias · 편향
입력과 무관하게 더해져 판단 기준을 이동시키는 값
Activation · 활성화 함수
신경망이 복잡한 비선형 관계를 표현하게 하는 함수
Feature · 특징
판단에 도움이 되도록 신경망이 학습한 패턴
Feature map · 특징 맵
CNN 필터가 특정 패턴이 어디에 있는지 표시한 출력
Hidden state
RNN이 앞의 정보를 압축해 다음 시점으로 넘기는 기억
Cell state
LSTM이 긴 구간에 걸쳐 정보를 운반하는 장기 기억 통로
Gate
LSTM에서 정보를 잊고, 저장하고, 꺼내는 조절 장치
Attention
입력 요소 사이의 관련도를 계산해 중요한 정보에 집중하는 방식
Q · K · V
Attention에서 질문, 표지, 실제 내용 역할을 하는 세 벡터
Parallelization · 병렬화
여러 계산을 순서대로 기다리지 않고 동시에 처리하는 것
Workload
모델 실행에 필요한 연산과 데이터 이동의 전체 작업량
DNN accelerator
지원되는 신경망 연산을 CPU보다 효율적으로 실행하도록 만든 하드웨어
