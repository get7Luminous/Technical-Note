Scaled dot-product attention

각 입력에서 Query, Key, Value 벡터를 만듭니다. Query와 모든 Key의 내적으로 관련도를 얻고, softmax로 정규화한 뒤 Value를 가중 합산합니다.

Attention(Q,K,V) = softmax(QKᵀ / √dₖ)V
Multi-head attention여러 attention head가 문법·의미·위치 등 서로 다른 관계를 동시에 학습합니다.
