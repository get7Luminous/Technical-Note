Affine transform과 activation의 반복

각 층은 입력 벡터에 가중치 행렬 W를 곱하고 편향 b를 더한 뒤 비선형 활성화 함수를 적용합니다.

h = σ(Wx + b)
Fully connected한 층의 모든 뉴런이 다음 층의 모든 뉴런과 연결됩니다.
비선형성ReLU 같은 activation이 단순 직선으로 풀 수 없는 경계를 학습하게 합니다.
강점구조가 단순하고 고정 길이 벡터 문제에 범용적으로 적용됩니다.
한계픽셀 위치나 시간 순서 같은 구조를 입력만으로는 알지 못합니다.
