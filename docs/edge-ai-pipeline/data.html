Edge AI / DATA

01. 데이터

학습 재료와 라벨 · train / validation / test

Input원시 센서 데이터
→
Output / Constraint라벨이 붙은 데이터셋
Dataset library태스크별 공개 데이터셋과 검색 허브 →

이미지, 오디오, 센서 데이터부터 라이선스와 입력 조건까지 확인합니다.

역할

모델이 배울 재료를 모으고, 정답(라벨)을 붙이고, 학습용 형태로 정리한다.

입력 → 산출물

원시 센서 데이터(이미지, 오디오, 진동 등) → 라벨이 붙은 train/validation/test 세트

세부 분류

  • 공개 데이터셋: ImageNet, COCO, MNIST/CIFAR, Speech Commands, AudioSet 등 (아래 1) 참고)
  • 라벨링 도구: CVAT, Label Studio, Roboflow → 바운딩 박스, 세그멘테이션 마스크, 클래스 태그를 사람이 찍는 도구
  • 전처리·증강(augmentation): 크기 조정, 정규화, 회전·반전·노이즈 추가. 오디오라면 FFT → 멜 스펙트로그램 변환이 여기에 속한다.

주의점

Edge AI에서는 배포 장치의 센서로 직접 모은 데이터가 공개 데이터셋보다 중요한 경우가 많다. 공개셋으로 사전학습된 모델을 가져오고, 자기 데이터로 미세조정(transfer learning)하는 조합이 표준이다.
