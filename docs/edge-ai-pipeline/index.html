Edge AI / Overview

Edge AI 파이프라인과 도구 분류

데이터에서 장치까지, 역할과 산출물로 읽는 7단계 지도.

이 7단계는 OSI 7계층 같은 공식 표준이 아니라 Edge AI의 역할과 도구를 이해하기 위한 분류입니다. 각 단계의 산출물을 보면 경계가 더 선명해집니다.

데이터셋 → 아키텍처 선택 → 학습 → 변환·양자화 → 장치에서 추론
  1. Stage 01 · 상세 보기 →데이터학습 재료와 라벨train / validation / test
  2. Stage 02 · 상세 보기 →알고리즘 계열문제를 푸는 방법론ML / CNN / RNN / Transformer
  3. Stage 03 · 상세 보기 →구체적 모델층 구성과 연산 설계MobileNet / YOLO / YAMNet
  4. Stage 04 · 상세 보기 →학습 프레임워크가중치를 최적화하는 도구TensorFlow / PyTorch / Keras
  5. Stage 05 · 상세 보기 →변환·최적화배포 형태와 정밀도 조정.tflite / .onnx / 벤더 포맷
  6. Stage 06 · 상세 보기 →추론 런타임장치에서 모델을 실행LiteRT / ONNX Runtime / TFLM
  7. Stage 07 · 상세 보기 →하드웨어실행 자원과 제약RAM / Flash / 전력 / 지연시간
