Edge AI / DATASETS

데이터셋 카탈로그

태스크에 맞는 공개 데이터셋을 찾고, 배포 센서와 데이터 조건을 함께 확인합니다.

1) 태스크별 공개 데이터셋이미지 분류객체 검출·세그멘테이션사람 검출 (Edge AI 특화)오디오센서·시계열 (IMU, 진동)벤치마크 스위트2) 어디서 찾는가 (허브)3) 고를 때 볼 것

일치하는 데이터셋이나 항목이 없습니다.

1) 태스크별 공개 데이터셋

이미지 분류

  • ImageNet (1,000클래스, 약 120만 장) 직접 학습보다는 MobileNet·ResNet 등 사전학습 가중치의 출처로 만나게 된다.
  • CIFAR-10/100 (32×32), Tiny ImageNet (64×64, 200클래스) 저해상도 경량 비전 과제의 표준 벤치마크.
  • MNIST, Fashion-MNIST 입문·파이프라인 검증용.
  • Flowers, Food-101, Oxford Pets 전이학습 실습용 소형 세트.

객체 검출·세그멘테이션

  • COCO (80클래스) YOLO·SSD 계열 사전학습의 표준. ImageNet, COCO, Open Images는 업계 표준 벤치마크.
  • Pascal VOC (20클래스) 오래됐지만 작아서 실습용으로 유용.
  • Open Images V7 구글 큐레이션, 900만 장 이상, 600개 객체 카테고리. 크기 때문에 다운로드·처리 부담이 크다.
  • LVIS COCO 호환 구조. 빈번한 클래스와 희귀 클래스를 모두 담아 롱테일 분포 학습에 사용. 인스턴스 세그멘테이션·오픈 보캐뷸러리 검출 연구에서 널리 쓰임.
  • Roboflow 100 (RF100) 9만 개 이상의 공개 데이터셋 중 100개를 골라 객체 검출 벤치마크용으로 구성. 의료, 항공, 문서 등 실제 산업 도메인이 섞여 있어 "내 도메인과 비슷한 소형 세트"를 찾기 좋다.

사람 검출 (Edge AI 특화)

  • Visual Wake Words (VWW) 사람이 프레임의 0.5% 이상을 차지하면 1, 없으면 0인 이진 분류. 학습 82,783장 / 테스트 40,504장. COCO에서 파생. MCU 카메라 프로젝트의 사실상 표준.
  • Wake Vision 500만 장 이상. Large(사전학습·증류용)와 Quality(고품질 라벨) 두 변형. Open Images V7에서 파생, VWW 대비 정확도 개선. 조명·거리·인구통계 조건별 견고성 벤치마크 제공. VWW의 후속 격.

오디오

  • Google Speech Commands 2018년 Google Brain 공개. 2,618명 화자의 105,829개 발화, 35개 단어. 오작동 방지용 배경 소음 샘플 포함. 키워드 스포팅(KWS)의 표준.
  • AudioSet YAMNet 학습 데이터. 유튜브 클립 라벨이라 원본 오디오는 직접 받아야 한다.
  • ESC-50, UrbanSound8K 환경음 분류(개 짖는 소리, 사이렌 등) 소형 세트.
  • ToyADMOS, MIMII 기계 작동음 이상 탐지용. ToyADMOS는 2019년 공개, 180시간 이상의 정상 작동음과 4,000개 이상의 이상음 샘플. 설비 이상 탐지 실습에 사용.
  • LibriSpeech, Common Voice (Mozilla) 음성 인식(STT)용. 엣지에서는 무겁지만 한국어 데이터가 있는 Common Voice는 참고할 만하다.

센서·시계열 (IMU, 진동)

  • UCI HAR, WISDM, MotionSense 스마트폰 가속도·자이로로 걷기/뛰기/계단 등 행동 인식.
  • PAMAP2, Opportunity 다중 센서 착용형 행동 인식.
  • NASA Bearing, CWRU Bearing 베어링 진동 이상 탐지(예지보전)의 고전.
  • 주의: 하나의 긴 연속 녹화를 무작위로 잘라 테스트 세트라고 부르면 안 된다. 샘플링 레이트·윈도우·오버랩·축 수·필터링·정규화를 학습 전에 정의하고, 여러 사용자·장착 위치·기계 상태에서 독립 세션을 수집해야 한다. 센서 데이터는 공개셋보다 자체 수집이 훨씬 중요한 영역이다.

벤치마크 스위트

  • MLPerf Tiny Visual Wake Words, Keyword Spotting, Anomaly Detection 세 과제로 구성. 데이터셋이라기보다 "이 세 데이터셋으로 이 모델을 돌려 비교하라"는 규격.

2) 어디서 찾는가 (허브)

  • Hugging Face Datasets (huggingface.co/datasets) 현재 가장 활발한 허브. datasets 라이브러리로 한 줄에 로드 가능. 이미지·오디오·텍스트 모두.
  • Kaggle (kaggle.com/datasets) 커뮤니티 업로드 데이터셋이 많고 노트북 예제가 함께 있어 입문에 좋음.
  • Roboflow Universe (universe.roboflow.com) 객체 검출용 소형 데이터셋 수만 개. YOLO/COCO 포맷으로 바로 내보내기 가능.
  • TensorFlow Datasets (TFDS) tfds.load('speech_commands')처럼 코드로 바로 받는 카탈로그. TF/Keras 파이프라인이면 가장 편함.
  • torchvision / torchaudio datasets PyTorch 쪽 동일 역할.
  • Papers with Code → Datasets 논문별 벤치마크 성능표와 함께 데이터셋 페이지 제공.
  • UCI Machine Learning Repository 전통 ML·센서 시계열 데이터의 고전 저장소.
  • Zenodo, IEEE DataPort 논문 부속 데이터가 올라오는 학술 저장소.
  • AI Hub (aihub.or.kr) 한국 정부(NIA) 운영. 한국어 음성·국내 영상 데이터. 국내 프로젝트라면 필수 확인.
  • 벤더 예제 데이터 Edge Impulse 공개 프로젝트, STM32 Model Zoo 등에 튜토리얼과 짝지어진 소형 데이터셋.

3) 고를 때 볼 것

  • 라이선스: 많은 연구용 데이터셋이 상업적 이용을 금지한다. 라이선스, 클래스 균형, 라벨 정확도를 함께 따진다. 학습용은 자유로워도 제품 탑재 시 문제가 되는 경우가 많다.
  • 입력 해상도·길이: 엣지 모델은 96×96, 1초 오디오처럼 작은 입력을 쓰므로 고해상도 데이터셋은 어차피 축소해서 쓴다. 처음부터 저해상도 세트로 실험하면 시간이 절약된다.
  • 출처 검증: LAION-5B는 규모에도 불구하고 부적절한 콘텐츠 링크가 발견되어 배포가 일시 중단된 적이 있다. 웹 크롤링 기반 대형 데이터셋은 이런 위험이 있어 검증된 큐레이션 세트를 우선하는 것이 안전하다.
