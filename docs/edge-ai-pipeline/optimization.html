Edge AI / OPTIMIZATION

05. 변환·최적화

배포 형태와 정밀도 조정 · .tflite / .onnx / 벤더 포맷

Input학습 산출물
→
Output / Constraint장치용 모델

역할

학습 산출물을 장치 런타임이 읽을 수 있는 포맷으로 바꾸고, 크기와 연산량을 줄인다. Edge AI가 클라우드 AI와 갈라지는 지점.

입력 → 산출물

SavedModel/.pt → .tflite / .onnx / 벤더 전용 포맷 (더 작고, 추론 전용)

세부 분류

  • 포맷 변환: TFLite Converter(TF → .tflite), torch.onnx.export(PyTorch → .onnx), tf2onnx ONNX는 프레임워크 간 "중간 언어" 역할. PyTorch로 학습하고 TF 생태계로 가져올 때 자주 쓴다.
  • 양자화: float32 → int8. 크기 약 1/4, 정수 연산만 있는 MCU에서 실행 가능. 학습 후 양자화(PTQ)와 양자화 인식 학습(QAT)으로 나뉘며, PTQ에는 대표 샘플(calibration data)이 필요.
  • 프루닝: 기여도 낮은 가중치를 0으로 만들어 희소화
  • 지식 증류: 큰 모델(teacher)의 출력을 작은 모델(student)이 흉내 내도록 재학습
  • 도구: TF Model Optimization Toolkit, ONNX Runtime quantization, TensorRT(NVIDIA), OpenVINO Model Optimizer(Intel)

주의점

변환 시 "지원하지 않는 연산자" 오류가 가장 흔하다. 모델(3단계)을 고를 때 목표 런타임(6단계)이 지원하는 연산자로만 구성됐는지 미리 확인해야 한다.
