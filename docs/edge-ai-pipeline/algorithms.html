Edge AI / ALGORITHMS

02. 알고리즘 계열

문제를 푸는 방법론 · ML / CNN / RNN / Transformer

Input문제와 입력의 특성
→
Output / Constraint알고리즘 계열 선택

역할

문제를 어떤 수학적 구조로 풀지 결정한다. 코드가 아니라 "방법론"이다.

세부 분류

  • 전통 ML: Random Forest, Gradient Boosting(XGBoost), SVM, k-NN, 로지스틱 회귀 특징(feature)을 사람이 설계해 넣어야 한다. 데이터가 적고 표 형태(센서 값 몇 개)일 때 강하다. 연산량이 매우 작아 MCU에도 잘 맞는다.
  • 딥러닝: CNN(이미지·스펙트로그램 같은 격자 데이터), RNN/LSTM/GRU(시계열·순서 데이터), Transformer(언어, 최근엔 비전도), MLP(단순 벡터 입력) 특징을 스스로 학습하지만 데이터와 연산이 많이 필요하다.

선택 기준

입력이 이미지/스펙트로그램이면 CNN, 표 형태 소량 데이터면 Random Forest부터 시도하는 것이 일반적.

주의

Random Forest는 딥러닝이 아니라 전통 ML이므로 TFLite/ONNX 흐름과 별개 경로 (scikit-learn → 직접 C 코드 변환 등)로 간다.
