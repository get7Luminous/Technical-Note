Edge AI / RUNTIMES

06. 추론 런타임

장치에서 모델을 실행 · LiteRT / ONNX Runtime / TFLM

Input모델 파일 + 실시간 입력
→
Output / Constraint클래스 · 박스 좌표 등 추론 결과
각 경로의 계산 결과 → 추론 결과

역할

변환된 모델 파일을 읽어 장치에서 실제 추론을 실행한다. 학습 기능은 없고, 해당 하드웨어에 맞는 커널(연산 구현)을 갖고 있다.

입력 → 산출물

모델 파일 + 실시간 입력 → 추론 결과(클래스, 박스 좌표 등)

세부 분류 (장치 급 기준)

  • 스마트폰·SBC(리눅스 급): TensorFlow Lite/LiteRT, ONNX Runtime, OpenCV DNN, NCNN, MNN, PyTorch Mobile/ExecuTorch
  • 특정 벤더 가속기: TensorRT(NVIDIA Jetson), OpenVINO(Intel), Core ML(Apple), Edge TPU 런타임(Google Coral)
  • MCU 급: TFLite Micro, CMSIS-NN(ARM 최적화 커널), microTVM, 벤더 코드 생성기(STM32Cube.AI, NXP eIQ 등 — 모델을 C 배열+함수로 변환)

주의점

같은 .tflite 파일이라도 런타임과 하드웨어 가속기(delegate/NPU) 조합에 따라 속도가 수십 배 차이 난다. 위임(delegate) — 지원되는 연산만 가속기에 넘기고 나머지는 CPU에서 실행 — 개념을 알아두면 성능 튜닝이 이해된다.
