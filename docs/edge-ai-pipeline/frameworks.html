04. 학습 프레임워크

가중치를 최적화하는 도구 · TensorFlow / PyTorch / Keras

Input데이터셋 + 모델 정의
→
Output / Constraint학습된 가중치 파일

역할

모델을 코드로 정의하고, 데이터를 흘려 가중치를 최적화(역전파)한다. GPU가 있는 PC/서버에서 돌린다.

입력 → 산출물

데이터셋 + 모델 정의 → 학습된 가중치 파일 (TF: SavedModel/.h5/.keras, PyTorch: .pt/.pth, sklearn: .pkl)

세부 분류

  • 딥러닝: TensorFlow, PyTorch, JAX 연구 커뮤니티는 PyTorch, TFLite로 가는 임베디드 배포 경로는 TensorFlow가 여전히 매끄럽다.
  • 고수준 API: Keras(TF 위), PyTorch Lightning(PyTorch 위) "층을 쌓는 코드"를 짧게 만들어 준다. Keras는 독립 프레임워크가 아니라 TensorFlow 위의 고수준 API (Keras 3부터는 PyTorch/JAX 백엔드도 지원). "TensorFlow로 학습했다"와 "Keras로 짰다"는 보통 같은 말.
  • 전통 ML: scikit-learn, XGBoost/LightGBM
  • 통합 도구: Ultralytics(YOLO 학습·변환 패키지), Edge Impulse(웹에서 1~6단계를 통합)

주의점

여기서 나온 파일은 float32이고 학습용 정보(옵티마이저 상태 등)까지 담고 있어 그대로 장치에 올리지 않는다.
