Edge AI / MODELS

03. 구체적 모델

층 구성과 연산 설계 · MobileNet / YOLO / YAMNet

Input아키텍처 정의 + 가중치
→
Output / Constraint모델 파일

역할

2번 계열을 특정 층 구성·연산 방식으로 설계한 것. 논문 단위로 이름이 붙고, 대개 사전학습 가중치가 함께 배포된다.

입력 → 산출물

아키텍처 정의(코드) + 학습된 가중치 = 모델 파일

세부 분류 (태스크 기준)

  • 이미지 분류: MobileNetV1/V2/V3, EfficientNet-Lite, ResNet, SqueezeNet 이름에 "Mobile", "Lite", "Tiny"가 붙으면 경량 설계.
  • 객체 검출: YOLO 계열, SSD, EfficientDet 분류 모델을 "백본"으로 쓰고 위에 검출 헤드를 얹는 구조가 많다 (예: SSD-MobileNetV2).
  • 얼굴 검출·인식: YuNet(검출), SFace(인식)
  • 오디오: YAMNet(소리 분류), DS-CNN(키워드 스포팅)
  • 세그멘테이션: DeepLab, U-Net

관계 정리

CNN(계열) ⊃ MobileNetV2(설계) ⊃ 학습된 가중치 파일(실제 산출물)

주의점

같은 이름이라도 크기 변형(YOLOv8n/s/m, MobileNetV2 α=0.35/1.0)이 있고, 엣지에서는 가장 작은 변형부터 본다. "백본"과 "헤드"를 구분하면 전이학습 시 어디를 얼리고 어디를 다시 학습하는지 이해가 쉬워진다.
